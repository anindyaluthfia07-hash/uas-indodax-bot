Bot Dry-Run Indodax:
Donchian Breakout + EMA + ATR Trailing Stop

Adaptasi strategi UTS ke pasar kripto IDR. Long-only, tanpa API key, tanpa leverage. Backtest 4 tahun memakai candle 4 jam, biaya taker all-in, spread dan slippage yang diukur dari order book publik. Forward test dijalankan pada bid/ask nyata.

Kurva ekuitas backtest

Modal awal Rp100 juta, dinormalisasi ke 100. Garis putus-putus = beli-dan-tahan BTC (benchmark).
